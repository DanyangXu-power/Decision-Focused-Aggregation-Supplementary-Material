# Supplementary material

[DFAM_Results.html](DFAM_Results.html) is a supplementary file accompanying the paper **“Aligning DER Flexibility with Grid Operational Needs: A Decision-Focused Aggregation Framework.”** It lets readers explore the inputs and results of two experiments reported in the paper.

- **T39–D6.** Explore a 39-bus transmission system connected to six active distribution networks. Select a network and a distributed energy resource (DER) node to compare a scenario’s hourly prices with the training bounds, inspect the aggregated power limits, and follow the upper and lower bounds across training iterations. The evaluation tab reports economic dispatch performance over 100 test scenarios.
- **Node-level performance.** Compare decision gaps for TAM, DFAM, and the virtual battery (VB) model across 12 DER clusters and 1,000 price realizations. The cross-evaluation table shows how the mean worst-case decision loss changes when the price ranges used for training and evaluation differ.

**How to use the file.** Open `DFAM_Results.html` in a web browser, choose **English** or **中文**, and select an experiment. All data needed to display the results are embedded in the file. It runs offline without installation, an account, or an optimization solver.
